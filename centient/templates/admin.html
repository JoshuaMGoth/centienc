💡 Why link a server?
Linking a website to a server with SSH access enables live traffic feed, visitor counts, device types, and connection types (ftp/ssh/http/https/sql) by parsing your web server's access logs (nginx/Apache).
Without a linked server, only uptime and response time monitoring is available.
