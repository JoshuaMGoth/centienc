FAQ

Common questions answered

New to infrastructure monitoring? Here are the questions we hear most often.

What exactly is server monitoring, and do I actually need it?

Server monitoring means continuously watching your infrastructure — CPU usage, memory, disk space, running processes, network traffic, and uptime — so you know immediately when something goes wrong. Without it, you find out about problems the same way your users do: when things break.

If you run a website, app, or any online service, monitoring is essential. It's the difference between fixing an issue in two minutes and finding out about it hours later from a frustrated user.

Do I need to be technical to use CentienC?

The install requires basic Linux command-line comfort — you'll need to run a one-line installer and have SSH access to your server. After that, everything is managed through a clean web dashboard built for humans, not just sysadmins.

If you can copy-paste a terminal command and own a server or VPS, you can run CentienC.

Is CentienC really free? What's the catch?

The server software is completely free and open-source under GNU GPLv3. The core monitoring experience — server health, website checks, live traffic, notifications, incident tracking — is free forever with no limits.

Pro features (deep analytics, reports, attack detection, and export) require a paid license. This is how the project sustains itself. The free tier is a fully functional monitoring system, not a crippled trial.

The companion iPhone app is free to download. It connects to your server and shows core monitoring data. When your server has a Pro license, the app automatically unlocks full analytics and reports on mobile too.

What do I get with a Pro license?

Pro unlocks the business intelligence layer of CentienC:

  • Deep web analytics — top pages, unique visitors, heatmaps, hourly/daily traffic patterns
  • Traffic intelligence — device types, browsers, traffic sources, search query extraction
  • Attack detection — SQL injection, XSS, path traversal, command injection, bot classification
  • Reports — SLA tracking, uptime reports, incident summaries, fail2ban reports
  • Export — CSV, HTML, and PDF report exports
  • Full iPhone app — all analytics and reports available on mobile

The license is tied to your server instance. All users and devices connecting to that server get Pro features — no per-seat charges.

How does the Pro license work technically?

You receive a license key after purchase (e.g. CENT-xxxxxxxxxx-XXXXXXXX). Paste it into your CentienC dashboard under Admin → License. The key is cryptographically verified locally — no "phone home" to our servers. Pro features unlock immediately.

The key is HMAC-signed and contains your tier and expiration date. Your CentienC install validates it entirely offline.

How is CentienC different from Grafana, Datadog, or Zabbix?

Grafana, Datadog, and Zabbix are powerful — but they're built for large engineering teams and require significant configuration to get anything useful out of them. Datadog is also expensive at scale.

CentienC is built for the individual developer, small team, or self-hoster who wants instant clarity without a week of setup. You install it, connect your servers, and your dashboard is populated. No PromQL, no complex agent configs, no bloat.

How does CentienC collect data from my servers?

CentienC uses SSH to connect to your target servers and collect metrics directly — CPU load, memory usage, disk space, running processes, nginx access logs, and fail2ban state. For Proxmox, it uses the Proxmox API with a read-only token.

Nothing is installed on your monitored servers. The CentienC backend polls them on a schedule, processes the data, stores it, and serves it to your dashboard and mobile app. Your servers stay clean.

Can I monitor multiple servers and websites at once?

Yes. CentienC is built for multi-target monitoring from the start. Add as many servers, websites, Proxmox nodes, and services as you need. Everything appears on a single unified dashboard.

Is my monitoring data sent to the cloud or kept private?

All data stays on your own server. CentienC is entirely self-hosted — metrics, logs, historical data, and credentials never touch an external cloud service. You run the backend, you own the database, and nothing leaves your infrastructure unless you explicitly configure an outbound notification (like a webhook or email alert).

What about the iPhone app? Do I need to pay separately?

The iPhone app is free to download. It connects to your self-hosted CentienC server and provides:

  • Free users: live health overview, push notifications, server/site status
  • Pro subscribers: full analytics, reports, attack detection — everything the web dashboard has, on your phone

There is no separate app subscription. The app reads the license status from your server. If your server has a Pro license, the app unlocks all features automatically.

Why can't the iPhone app connect directly to my servers without the CentienC backend?

It's technically possible — iOS can make SSH connections — but it would be a genuinely bad experience. Here's why the backend architecture isn't optional:

Without a backend (direct SSH from iPhone): The app would have to re-parse raw log files from scratch every time you open it. A 500MB nginx log would drain your battery and take minutes to render. iOS aggressively kills background apps, so there would be no monitoring while the app is closed, no push notifications possible, and any data from periods when the app was closed would be gone once logs rotate. SSH keys stored on your phone also become a serious security risk if your device is lost or stolen.

With the CentienC backend: Your server runs 24/7 doing all the heavy lifting — parsing logs, aggregating metrics, storing history in a database. The iPhone app simply calls an API endpoint and receives pre-computed JSON. Charts render instantly from small payloads, not raw files. Push notifications work because the backend monitors continuously and pings Apple's push service when thresholds are crossed. Your SSH keys and credentials never leave your server. Multiple devices and users can share the same live dashboard.

How often does data refresh on the dashboard?

The live request feed updates in near real-time. Server metrics and uptime checks poll on a configurable interval (default: every 30–60 seconds). Historical aggregates update continuously in the background.

What happens if my monitored server goes offline?

CentienC marks the target as unreachable on the dashboard and triggers any configured alerts (webhook, email, Discord, push notification). The dashboard clearly shows which services are down vs. healthy, so you always know the current state of your infrastructure at a glance.
